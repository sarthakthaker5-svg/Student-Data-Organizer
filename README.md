# Student Data Organizer

* A beginner-friendly Python project that manages student records using Lists, Tuples, Sets, and Dictionaries. This project helps beginners understand Python collections, string formatting, type casting, mutability, immutability, and menu-driven programming.

## Project Objective

* The main goal of this project is to help beginners understand how Python handles:

* User input

* String formatting

* Lists

* Tuples

* Sets

* Dictionaries

* Type casting

* Mutability and immutability

* Data management

* Menu-driven programs

## Features

* Displays a menu-driven program
* Adds new student records
* Displays all student records
* Updates student information
* Deletes student records using the `del` keyword
* Displays unique subjects offered
* Uses tuples for immutable student data
* Uses dictionaries for organizing student details
* Beginner-friendly and easy to understand

## Program Workflow

1. Display the welcome message

2. Show the menu options:

   * Add Student
   * Display All Students
   * Update Student Information
   * Delete Student
   * Display Subjects Offered
   * Exit Program

3. Take user input for menu selection

4. Perform the selected operation:

   * Add and store student details
   * Display all student records
   * Update age or subjects of a student
   * Delete a student record
   * Display all unique subjects

5. Continue running until the user selects Exit

## Data Structures Used

### List

Stores all student records.

### Tuple

Stores immutable student information:

* Student ID
* Date of Birth

### Set

Stores unique subjects and prevents duplicates.

### Dictionary

Stores:

* Student Name
* Age
* Grade
* Subjects
* Student Information Tuple

## Learning Outcomes

After completing this project, learners will understand:

* How to use Lists, Tuples, Sets, and Dictionaries
* How to create menu-driven applications
* How to update and delete records
* How to perform type casting
* How to use string formatting
* How Python handles mutable and immutable data types
